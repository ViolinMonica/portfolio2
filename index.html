Technical detail

Fortune Cookie Machine pyjail · easy · python

A Python sandbox-escape challenge served over the network, running user input through eval with builtins stripped and a blocklist that breaks common copy-paste payloads, forcing players to reason about MRO traversal and list comprehensions to reach a file read. Packaged for deployment with nsjail (redpwn/jail), Docker, and CTFd metadata.

hacked Reverse Engineering · easy · Pyc

A .pyc reversing challenge that decompiles to a layered XOR + zlib + base64 loader, based on a real self-propagating file-encryptor, teaching players to analyze bytecode before running untrusted code.

tali Reverse Engineering · easy · C

A beginner reversing/forensics challenge hiding a reversed base64 string in a binary's .rodata, solvable with strings and basic decoding.

clockmod Reverse Engineering · medium · C

A reversing challenge built around a custom stateful stream cipher, wrapped in three layers of anti-debugging (ptrace self-trace, TracerPid check, and RDTSC timing) that feed wrong results to anyone debugging without bypassing the protections first. Recover the key one byte at a time to solve.
